# Pingdom landing page

플랫폼 소개 → 기획 배경 → 기능 설명 → 팀 소개 순서의 정적 랜딩페이지입니다.

## 로컬 실행

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

프레임워크, 외부 API, 빌드 과정 없이 동작합니다. HTML은 콘텐츠, CSS는 레이아웃·반응형·모션, JavaScript는 기능 탭과 스크롤·포인터 반응을 담당합니다.

## 인터랙션

- 네 기능 탭: 앱 이미지, 핵심 문구, 태그 전환.
- 탭 방향키·Home·End 탐색 및 키보드 접근.
- 마우스에 반응하는 히어로 비주얼, 스크롤 시차와 섹션 등장. 대각선 타이포그래피와 중앙 입체 비주얼을 겹쳐 배치.
- 상점주·관리자별 3가지 기능 화면 선택 및 확대 모달. 원본 크기 보기, Escape 닫기, 포커스 복귀.
- 세 단계 신뢰 정보를 순서대로 펼쳐 보여주는 구성.
- Pingdom AI: 질문 선택, 장소 카드와 응답 전환. 상권 컨설팅: 지역·업종 선택에 따른 예시 리포트 전환.
- 이름 목록에서 7명 팀원 선택, 발표자료 프로필과 담당 업무 상세. 김일강·이용인 사진 연결은 사용자의 최신 교정 요청 반영.
- 히어로 리본 조형의 각도를 고정한 부유와 배경 조명 애니메이션. 멈춤 버튼과 운영체제의 동작 줄이기 설정을 반영하며, 화면 밖이나 비활성 탭에서는 정지.
- 첫 접속에는 왼쪽에서 빠르게 들어오는 미세 입자 → 위·아래 곡면으로 갈라지는 흐름 → 감속하며 표면에 정착 → 금속 재질과 제목·메뉴 순서로 약 5.4초의 인트로를 재생합니다. 건너뛰기 버튼은 없으며, Escape·Tab·스크롤 입력과 동작 줄이기·뒤로 가기·하위 섹션 직접 진입은 즉시 본문으로 연결합니다. 이미지 준비 실패나 GPU·모듈 로딩 실패 시에도 본문을 복구합니다.
- 기존 링 PNG에서 입자의 도착점과 색을 추출하고 WebGL에서 위치·재질 전환을 계산합니다. 모바일은 입자 수를 줄이고, 해상도 배율은 최대 2배로 제한합니다. 종료·중단 시 프레임 루프와 GPU 자원을 해제합니다.
- 모션 참고: [Codrops — Emissive Dissolve Effect](https://tympanus.net/codrops/2025/02/17/implementing-a-dissolve-effect-with-shaders-and-particles-in-three-js/). 입자와 재질 경계를 공유하는 원리를 참고해 기존 링 이미지가 조립되는 방향으로 구현했습니다. 입자는 화면 왼쪽 밖에서 출발해 링의 위·아래 곡면으로 나뉩니다. 진입 곡선과 곡면 경로의 접선 속도를 맞추고, 입자별 도착 시점·감속·흐름의 흔들림을 달리해 고정된 표면에 정착시킵니다. 금속 표면은 위치별 입자가 도착한 뒤 나타나며, 작은 입자와 긴 잔광·부드러운 전경 입자의 크기와 밝기를 구분합니다. 데스크톱의 입자 샘플을 약 5배로 늘리고 곡선 잔광과 1/4 해상도 빛 번짐을 추가했습니다. 모바일은 입자 샘플과 잔광 수를 제한하며 모든 임시 버퍼는 종료 시 해제합니다. 참고 데모의 코드나 자산은 포함하지 않습니다.

## 자료와 표현

- 사용자 제공 발표자료 26쪽과 포트폴리오 58쪽을 기준으로 작성.
- 사용자 제공 7개 시각 레퍼런스의 큰 타이포, 비대칭 구도, 입체 소재, 강한 색 대비를 반영.
- 실제 앱·웹 화면과 7명 팀 담당 업무는 포트폴리오에서 확인. 프로필 사진은 발표자료 26쪽을 사용. 이름·역할의 최종 기준은 포트폴리오 57–58쪽.
- 소비자 Pingdom AI와 사업자 AI 컨설팅을 구분.
- 다운로드, 로그인, 예약, AI 호출은 연결하지 않은 소개용 사이트.

## 검증

- JavaScript 구문 검사, 로컬 파일·앵커·중복 ID 검사 통과.
- 데스크톱 및 320px·390px 모바일에서 가로 넘침 없음.
- 마우스 클릭, Enter, Home, End로 기능 내용·화면 전환 확인.
- 브라우저 콘솔 오류 및 로드 완료 이미지의 깨짐 없음.
- 실제 기기·서비스 API 연동·전체 E2E 테스트는 수행하지 않음.

원본 생성 비주얼과 글꼴 정보는 ASSETS.md를 참고하세요.

## 브라우저 피드백 반영

- 상단 영문 보조 문구, 섹션 번호, 중복 설명과 핑크 띠 제거.
- AI 두 서비스의 보조 설명, 운영 화면 하단 캡션과 장식 화살표 제거. 푸터 링크는 “처음으로”로 표기.
- 기획 배경의 해결 문구를 더 큰 핑크 타이포와 등장 밑줄로 강조.
- 기획 배경: 세 열 카드 대신 문제에서 해결로 이어지는 문장 배치.
- 신뢰 정보: 인증서 카드를 없애고 상점주 제공·방문자 확인·핑덤 검증을 한눈에 보여주는 구성.
- 운영 화면: 기능 선택 목록과 실제 웹 화면을 나란히 배치하고 원본 크기 확대 제공.
- AI: 발표자료의 대화·추천·리포트 흐름을 HTML/CSS로 다시 구현하고 두 서비스의 사용 맥락 구분.
- 팀: 검은 사진 배경을 제거하고 테두리 없는 원형 프로필·이름·담당 업무를 밝은 단일 지면으로 구성.

AI 영역은 스크린샷이 아닌 네이티브 웹 요소로 구현했습니다. 장소 이미지·대화·차트는 소개용 예시이며 실제 검색이나 분석 API를 호출하지 않습니다. 상권 컨설팅을 선택하면 제목도 함께 전환됩니다.

## 원본 이미지와 표시 품질

- 앱 화면 8개는 포트폴리오에 포함된 1800×3680 원본 PNG를 직접 추출했습니다. 기존 800px WebP를 대체합니다.
- 상점주·관리자 화면 6개는 포트폴리오에서 1863–2908px 너비 원본 PNG를 직접 추출했습니다.
- 화면 내 문구를 재생성하지 않고 원본 그대로 표시하며, 확대 모달에서 원본 크기로 볼 수 있습니다.
- 앱·운영 화면은 탭에 포인터를 올리거나 키보드 포커스를 옮기면 미리 준비합니다. 작은 프로필 사진은 팀 영역에 접근할 때 준비하며, 첫 화면에서 모든 원본 PNG를 다운로드하지 않습니다.
- 앱·운영·팀·확대 화면은 표시할 이미지의 디코딩이 끝난 뒤 교체합니다. 앱의 두 이미지와 문구도 함께 바뀌며, 이전 선택의 지연 응답은 무시합니다.
- 중복 이미지 요청을 합치고 디코딩 캐시는 최대 4개를 유지합니다. 로딩 중 이전 내용을 숨기며, 실패하거나 15초가 지나면 다시 시도할 수 있습니다.
- AI 제목과 푸터는 웹 타이포그래피로 구성하고, 헤더는 제공받은 워드마크를 유지합니다.
- 첫 화면은 원본 레퍼런스의 대형 타이포그래피·중첩 구도·입체 소재를 기준으로 전면 재구성했습니다. 검은 바탕의 자주빛 배경에 리본형 3D 비주얼을 중앙 배치하고, 핵심 문장을 대각선으로 이어갑니다. 도시 사진·핀·구체·궤도 장식은 화면에서 제거했습니다. 배경과 조형은 포인터에 서로 다른 깊이로 반응하며 모바일에서는 세로 구도로 배치합니다.

## 이미지 전환 회귀 검증

```sh
node --test tests/panel-images.test.mjs
```

지연 응답의 역전, 두 이미지의 동시 교체, 디코딩 완료 대기, 이전 요청의 실패, 재시도, 모달 닫기, 요청 재사용·캐시 제한, 타임아웃을 확인합니다. DOM/Image 대역으로 완료 순서를 제어하는 단위 테스트이며, 실제 네트워크 속도 측정이나 전체 E2E 테스트를 대신하지 않습니다.

## 인트로 회귀 검증

```sh
node --test tests/hero-intro.test.mjs
```

인트로 종료·중단 후 스크롤 잠금·임시 효과·프레임 루프·GPU 자원 정리, 지연 이미지 도착, 디코딩·GPU·모듈 실패 시 복구, 동작 줄이기·직접 진입 생략을 DOM/Animation/렌더러 대역으로 검증합니다. 실제 셰이더와 모션·최종 배치는 브라우저에서 별도로 확인합니다.
