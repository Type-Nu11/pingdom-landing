# Pingdom landing page

플랫폼 소개 → 기획 배경 → 기능 설명 → 팀 소개 순서의 정적 랜딩페이지입니다.

## 로컬 실행

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

프레임워크, 외부 API, 빌드 과정 없이 동작합니다. HTML은 콘텐츠, CSS는 레이아웃·반응형·모션, JavaScript는 기능 탭과 스크롤·포인터 반응을 담당합니다.

## 인터랙션

- 네 기능 탭: 앱 이미지, 핵심 문구, 태그 전환.
- 탭 방향키·Home·End 탐색 및 키보드 접근.
- 마우스에 반응하는 히어로 비주얼, 스크롤 시차와 섹션 등장.
- 운영 화면·팀원 이미지의 호버 반응.
- 운영체제의 동작 줄이기 설정 반영. 자동 반복 애니메이션 없음.

## 자료와 표현

- 사용자 제공 발표자료 26쪽과 포트폴리오 58쪽을 기준으로 작성.
- 사용자 제공 7개 시각 레퍼런스의 큰 타이포, 비대칭 구도, 입체 소재, 강한 색 대비를 반영.
- 실제 앱·웹 화면과 7명 팀 정보는 포트폴리오에서 추출. 이름·역할의 최종 기준은 포트폴리오 57–58쪽.
- 소비자 Pingdom AI와 사업자 AI 컨설팅을 구분.
- 다운로드, 로그인, 예약, AI 호출은 연결하지 않은 소개용 사이트.

## 검증

- JavaScript 구문 검사, 로컬 파일·앵커·중복 ID 검사 통과.
- 데스크톱 및 320px·390px 모바일에서 가로 넘침 없음.
- 마우스 클릭, Enter, Home, End로 기능 내용·화면 전환 확인.
- 브라우저 콘솔 오류 및 로드 완료 이미지의 깨짐 없음.
- 실제 기기·서비스 API 연동·전체 E2E 테스트는 수행하지 않음.
