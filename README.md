# Pingdom landing page

플랫폼 소개 → 기획 배경 → 기능 설명 → 팀 소개 순서의 정적 랜딩페이지입니다.

## 로컬 실행

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

프레임워크, 외부 API, 빌드 과정 없이 동작합니다. HTML은 콘텐츠, CSS는 레이아웃·반응형·모션, JavaScript는 기능 탭과 스크롤·포인터 반응을 담당합니다.

## 인터랙션

- 네 기능 탭: 앱 이미지, 핵심 문구, 태그 전환.
- 탭 방향키·Home·End 탐색 및 키보드 접근.
- 마우스에 반응하는 히어로 비주얼, 스크롤 시차와 섹션 등장.
- 상점주·관리자별 3가지 기능 화면 선택 및 확대 모달. 원본 크기 보기, Escape 닫기, 포커스 복귀.
- 세 단계 신뢰 정보를 순서대로 펼쳐 보여주는 구성.
- Pingdom AI: 질문 선택, 장소 카드와 응답 전환. 상권 컨설팅: 지역·업종 선택에 따른 예시 리포트 전환.
- 이름 목록에서 7명 팀원 선택, 발표자료 프로필과 담당 업무 상세. 김일강·이용인 사진 연결은 사용자의 최신 교정 요청 반영.
- 운영체제의 동작 줄이기 설정 반영. 자동 반복 애니메이션 없음.

## 자료와 표현

- 사용자 제공 발표자료 26쪽과 포트폴리오 58쪽을 기준으로 작성.
- 사용자 제공 7개 시각 레퍼런스의 큰 타이포, 비대칭 구도, 입체 소재, 강한 색 대비를 반영.
- 실제 앱·웹 화면과 7명 팀 담당 업무는 포트폴리오에서 확인. 프로필 사진은 발표자료 26쪽을 사용. 이름·역할의 최종 기준은 포트폴리오 57–58쪽.
- 소비자 Pingdom AI와 사업자 AI 컨설팅을 구분.
- 다운로드, 로그인, 예약, AI 호출은 연결하지 않은 소개용 사이트.

## 검증

- JavaScript 구문 검사, 로컬 파일·앵커·중복 ID 검사 통과.
- 데스크톱 및 320px·390px 모바일에서 가로 넘침 없음.
- 마우스 클릭, Enter, Home, End로 기능 내용·화면 전환 확인.
- 브라우저 콘솔 오류 및 로드 완료 이미지의 깨짐 없음.
- 실제 기기·서비스 API 연동·전체 E2E 테스트는 수행하지 않음.

원본 생성 비주얼과 글꼴 정보는 ASSETS.md를 참고하세요.

## 브라우저 피드백 반영

- 상단 영문 보조 문구, 섹션 번호, 중복 설명과 핑크 띠 제거.
- 기획 배경: 세 열 카드 대신 문제에서 해결로 이어지는 문장 배치.
- 신뢰 정보: 인증서 카드를 없애고 상점주 제공·방문자 확인·핑덤 검증을 한눈에 보여주는 구성.
- 운영 화면: 기능 선택 목록과 실제 웹 화면을 나란히 배치하고 원본 크기 확대 제공.
- AI: 발표자료의 대화·추천·리포트 흐름을 HTML/CSS로 다시 구현하고 두 서비스의 사용 맥락 구분.
- 팀: 이름 목록과 큰 프로필을 분리하고, 선택한 사람의 역할과 담당 업무 전환.

AI 영역은 스크린샷이 아닌 네이티브 웹 요소로 구현했습니다. 장소 이미지·대화·차트는 소개용 예시이며 실제 검색이나 분석 API를 호출하지 않습니다. 상권 컨설팅을 선택하면 제목도 함께 전환됩니다.

## 원본 이미지와 표시 품질

- 앱 화면 8개는 포트폴리오에 포함된 1800×3680 원본 PNG를 직접 추출했습니다. 기존 800px WebP를 대체합니다.
- 상점주·관리자 화면 6개는 포트폴리오에서 1863–2908px 너비 원본 PNG를 직접 추출했습니다.
- 화면 내 문구를 재생성하지 않고 원본 그대로 표시하며, 확대 모달에서 원본 크기로 볼 수 있습니다.
- 앱 이미지를 모두 미리 로드하지 않고 선택한 화면만 불러옵니다.
- AI 제목과 푸터는 웹 타이포그래피로 구성하고, 헤더는 제공받은 워드마크를 유지합니다.
- 첫 화면은 도시 배경의 오른쪽에 크기를 줄인 3D 핀을 배치합니다. 핀 외부와 중앙 구멍만 투명하게 처리해 금속 표면이 배경에 비치지 않도록 했습니다. 배경과 핀은 포인터에 서로 다른 깊이로 반응하며 모바일에서는 제목 아래에 핀을 표시합니다.
