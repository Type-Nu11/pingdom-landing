# 원래 고가도로의 장노출 모션

8초·1920×1080·30fps 단일 고정 장면. 원래 `assets/plate.png`의 서울 skyline과 직선 고가도로를 유지한다. 교차로와 X 곡선은 사용하지 않는다.

기존 6차선과 `691+94*u-40*u²` 도로 높이를 그대로 사용한다. 차선마다 4가닥, 총 24가닥의 금빛·따뜻한 흰색 연속 ribbon을 만든다. 좁은 코어와 가닥별 밝기차를 유지하고, 950–1650px 잔광과 밝기 pulse를 빠르게 이동시킨다. 빛은 아스팔트 범위로 clip한다.

단일 GSAP paused timeline, seed 29092026, `ease: none`. 각 가닥의 4개 pulse가 8초에 4·5·6회 정수 순환하여 t=0과 t=8이 같다. 1800px guard는 잔광보다 길어 wrap이 화면 밖에서 일어난다. 모바일은 중앙 720×1080 crop.

검증: 원본 유지·6차선 정합·연속 가닥 snapshot을 먼저 검토한 뒤 HyperFrames check와 실제 render를 수행한다. 최종 H.264 ffprobe·압축 프레임·루프 경계 변화량을 확인한다.
