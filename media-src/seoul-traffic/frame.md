# 서울 도로 야경 배경

차분한 밤서울의 고정된 건물과 고가도로를 대비시켜, 차량의 빠른 긴 빛만 움직이는 현실적인 타임랩스를 만든다.

- 배경: 원본 plate의 남청색 밤하늘과 따뜻한 도시 창문.
- 초점: 하단 도로의 양방향 라이트 궤적.
- 가장자리 기준: 도로는 왼쪽 y≈0.73, 오른쪽 y≈0.80을 지나며 실제 plate 곡률에 정합한다.
- 보조 디테일: paired headlights, 긴 얇은 코어, 제한된 halo, 도로에만 생기는 반사.
- 색: 전조등 #fff4de / #ffdca3, 후미등 #ff5948, 반사 #e89e66.
- 글자 없음. 폰트는 사용하지 않는다.
- 건물·하늘·고가도로는 움직이지 않는다. 장난감 같은 네온과 강한 빛번짐은 배제한다.
