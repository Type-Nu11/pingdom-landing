# 장노출 교차로 배경

밤서울의 고정된 건물과 넓은 교차로 위에 빠르게 움직이는 밝기 덩어리와 길게 이어지는 잔광을 합성한다. 사용자 참고사진의 연속 곡선 교통 궤적이 시각 기준이다.

- 배경: 원본 intersection plate의 남청색 하늘·따뜻한 창문·빈 아스팔트.
- 초점: 중앙에서 교차하고 크게 회전하는 금빛·따뜻한 흰색의 긴 가닥.
- 원근: 멀수록 폭·차선 간격 축소. 건물·인도·중앙 섬을 피하며 전경 수목은 빛을 가린다.
- 디테일: 좁은 white-hot core, 금빛 감쇠 잔광, 작은 diffuse halo, 반대 방향 일부 warm red.
- 글자·폰트·UI·카메라 이동 없음. 짧은 직사각형 막대 반복과 점선 같은 노출을 피한다.
